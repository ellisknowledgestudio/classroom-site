Algorithms: Program the Robot 🤖

An algorithm is a set of step-by-step instructions. Computers follow instructions exactly, so every step has to be right! Build programs to guide the robot to the star, find and fix bugs, and use loops to make your programs shorter. Ages 7-11.

Program the robot

Tap the command buttons to build a program, then press Run. The robot only moves when you run the program. Turn commands spin the robot on the spot without moving it.

Tip: tap a block in your program to remove it. Think about which way the robot is facing before you turn. Turning left and right is from the robot's point of view, so pretend you are the robot!

Debug it

A mistake in a program is called a bug, and fixing it is called debugging. Each of these programs has one bug. Run it to see what goes wrong, then tap the wrong block to change it (Forward → Turn left → Turn right). Run again to test your fix.

Loops: repeat it!

A loop repeats some commands so you don't have to write them again and again. Press Repeat, add the commands to repeat, then press End repeat. Tap a Repeat block to change how many times it repeats. Each level has a block limit, so you'll need loops to fit!

Look for patterns: if you can see the same few moves happening again and again, that's a job for a loop. Real programmers use loops all the time.
