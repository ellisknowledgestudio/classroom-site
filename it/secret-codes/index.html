Secret Codes: Encryption 🔐

Encryption scrambles a message so only someone with the key can read it. Turn a Caesar cipher wheel to send secret messages, crack codes like a spy, and use letter counting to break a code without the key. Ages 9-14.

The Caesar cipher wheel

Julius Caesar sent secret orders by moving every letter a set number of places along the alphabet. The number of places is the key. Turn the wheel to choose a key, then type a message.

Words to know: the normal message is the plaintext. The scrambled message is the ciphertext. The key is the secret that turns one into the other. To decrypt, you move the letters back the other way.

Crack the code 🕵️

Decode each secret message and type what it says. The first ones tell you the key. Later on, you have to find the key yourself! Cracked: 0 ·

Brute force: a Caesar cipher only has 25 useful keys, so a code breaker can simply try them all until the message makes sense. That is why real encryption uses keys with billions and billions of possibilities.

Frequency detective 📊

In English, E is the most common letter. In a long secret message, the most common code letter is probably E in disguise. Find the tallest bar, tap it, and the key will be worked out for you.
