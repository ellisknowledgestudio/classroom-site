Pixels and Images 🖼️

Every picture on a screen is made of tiny squares of colour called pixels, and every pixel is stored as binary. See how resolution and colour depth change a picture, paint pixel art in binary, decode secret pictures and work out how big an image file is. Ages 9-13.

Resolution and colour depth

Resolution is how many pixels make up the picture. Colour depth is how many bits are used to store the colour of each pixel. Change them and watch the picture and the file size.

The trade-off: more pixels and more bits per pixel give a sharper, more realistic picture, but a bigger file that takes up more storage and takes longer to send.

Paint in binary

Choose a colour, then tap or drag on the grid. The computer stores each row as a line of binary. With 1-bit colour each pixel is one bit (0 or 1). With 2-bit colour each pixel needs two bits, so you get 4 colours.

Decode the picture 🔍

Each line of binary is one row of pixels: 1 = black, 0 = white. Paint the grid to match the code, then press Check.

Work out the file size

To find how much storage an image needs: width × height × colour depth = size in bits. Then divide by 8 to get bytes.

Units: 8 bits = 1 byte. 1,000 bytes = 1 kilobyte (KB). 1,000 KB = 1 megabyte (MB). Some computers count 1,024 instead of 1,000, so you may see both.
