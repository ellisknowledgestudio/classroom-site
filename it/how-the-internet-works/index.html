How the Internet Works 🌐

The internet is a giant network of computers joined together. Send a message and watch it split into packets that race through routers, find out how your browser finds a website, test how strong a password is, and learn to stay safe online. Ages 9-13.

Messages travel in packets

Data is not sent across the internet in one big piece. It is chopped into small packets. Each packet is labelled with where it is going, where it came from and its number. Routers pass the packets along, and each packet can take a different route.

Tap a router to break it (or fix it again). Packets will find another way round.

Why packets? Small packets share the network fairly, and if one gets lost only that packet has to be sent again. If a router breaks, packets simply go another way, so the internet keeps working.

How your browser finds a website

Every computer on the internet has an IP address: four numbers like 198.51.100.7. People prefer names, so a DNS server works like the internet's phone book, turning a website name into its IP address.

Password power 🔐

A strong password is long and hard to guess. Try some made-up passwords to see how long a computer would take to guess them. Never type a real password here or anywhere you don't trust. (This checker runs only on your device and nothing is sent anywhere.)
