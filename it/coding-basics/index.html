Coding Basics: Variables, If and Loops 🧩

Programs are built from a few big ideas: variables remember values, if blocks make decisions and loops repeat things. Predict what each block program will do, then step through it and watch the variables change. Finally, hunt down the bugs! Ages 9-13.

Debug it 🐞

Each program has one bug: a block that stops it doing what it should. Read the goal, run the program to see what goes wrong, then tap the block with the bug.
