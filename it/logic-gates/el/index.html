Πώς Λειτουργεί το Διαδίκτυο 🌐

Το διαδίκτυο είναι ένα τεράστιο δίκτυο από υπολογιστές συνδεδεμένους μεταξύ τους. Στείλε ένα μήνυμα και δες το να χωρίζεται σε πακέτα που τρέχουν μέσα από δρομολογητές, μάθε πώς ο φυλλομετρητής σου βρίσκει μια ιστοσελίδα, δοκίμασε πόσο ισχυρός είναι ένας κωδικός και μάθε να μένεις ασφαλής στο διαδίκτυο. Ηλικίες 9-13.

Τα μηνύματα ταξιδεύουν σε πακέτα

Τα δεδομένα δεν στέλνονται στο διαδίκτυο σε ένα μεγάλο κομμάτι. Κόβονται σε μικρά πακέτα. Κάθε πακέτο έχει ετικέτα με το πού πηγαίνει, από πού ήρθε και τον αριθμό του. Οι δρομολογητές (routers) προωθούν τα πακέτα και κάθε πακέτο μπορεί να πάρει διαφορετική διαδρομή.

Πάτησε έναν δρομολογητή για να τον χαλάσεις (ή να τον επισκευάσεις ξανά). Τα πακέτα θα βρουν άλλο δρόμο.

Μήνυμα που έφτασε στον διακομιστή

Γιατί πακέτα; Τα μικρά πακέτα μοιράζονται το δίκτυο δίκαια και, αν χαθεί ένα, μόνο αυτό το πακέτο πρέπει να ξανασταλεί. Αν χαλάσει ένας δρομολογητής, τα πακέτα απλώς πάνε από άλλο δρόμο, έτσι το διαδίκτυο συνεχίζει να λειτουργεί.

Πώς ο φυλλομετρητής σου βρίσκει μια ιστοσελίδα

Κάθε υπολογιστής στο διαδίκτυο έχει μια διεύθυνση IP: τέσσερις αριθμούς όπως 198.51.100.7. Οι άνθρωποι προτιμούν τα ονόματα, γι' αυτό ένας διακομιστής DNS λειτουργεί σαν τον τηλεφωνικό κατάλογο του διαδικτύου και μετατρέπει το όνομα μιας ιστοσελίδας στη διεύθυνση IP της.

Πάτησε τα βήματα με τη σωστή σειρά, από το να γράψεις τη διεύθυνση ως το να δεις τη σελίδα.

Το ήξερες; Καθένας από τους τέσσερις αριθμούς μιας διεύθυνσης IP πηγαίνει από 0 ως 255. Αυτό είναι ακριβώς ένα byte, οπότε μια τέτοια διεύθυνση IP έχει μήκος 32 bit.

Η δύναμη του κωδικού 🔐

Ένας ισχυρός κωδικός είναι μεγάλος και δύσκολος να μαντέψει κανείς. Δοκίμασε μερικούς φανταστικούς κωδικούς για να δεις πόσο θα χρειαζόταν ένας υπολογιστής για να τους μαντέψει. Μη γράψεις ποτέ αληθινό κωδικό εδώ ή οπουδήποτε δεν εμπιστεύεσαι. (Ο έλεγχος γίνεται μόνο στη συσκευή σου και τίποτα δεν στέλνεται πουθενά.)

Γράψε έναν κωδικό για να τον δοκιμάσεις.
    Δοκίμασε:

    Συμβουλή: ένωσε τρεις τυχαίες λέξεις μεταξύ τους, όπως mov-tigri-synnefo. Είναι μεγάλος, εύκολος να τον θυμάσαι και πολύ δύσκολος να τον μαντέψει κανείς. Χρησιμοποίησε διαφορετικό κωδικό για κάθε λογαριασμό και μην τον πεις ποτέ σε φίλους.
